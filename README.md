# CleanCity+ ️

CleanCity+ is an educational and interactive web platform designed to promote responsible waste management and recycling habits.  
Users can **learn about waste management**, **log and track their recycling contributions**, **pledge eco-friendly actions**, and **stay motivated with progress visualizations and achievement badges**.

---

## 🌟 Features

### Homepage
- Responsive **Bootstrap navigation bar** (Home, Waste Categories, Recycling Tracker, Pledge)
- **Hero section** with sustainability call-to-action
- **Recycling impact carousel** with rotating environmental facts

### Waste Categories Page
- **Accordion layout** with descriptions for: Plastic, Organic, Paper, Glass, and E-Waste
- **Disposal tips and images** for each category
- **“Did You Know?” Eco Fact Generator** (Recycling & waste management facts with button-based reveal)

### Recycling Tracker Page
- Form to **log recycled items** (category + quantity)
- **Data stored in localStorage** 
- **Search & Sort functions**
- **Editable table entries**
- **Progress visualization via Chart.js** 
- **Achievement Badge** unlocked when recycling more than 10 items in a category

### Pledge Page
- Users can **submit sustainability pledges** (e.g., “Recycle 5 bottles weekly”)
- **List group display** of all pledges
- **Live counter** showing total number of pledges
- Pledges also **persisted in localStorage**
